# 已知限制

本插件当前不支持的场景，以及受宿主环境限制无法实现的行为。

## 剪贴板

- Windows 支持双向文本和文件/文件夹剪贴板；远端到本地优先使用 OLE 虚拟文件按需读取，失败时回退到临时目录下载后发布文件列表。兼容回退需要等待下载完成后再次粘贴。
- Linux/macOS **仅同步文本**（`CF_UNICODETEXT`），不协商文件流，不支持文件或文件夹复制粘贴。
- 不支持位图剪贴板。Windows 原生复制进度是否出现由接收粘贴的应用决定，并非所有应用都支持虚拟文件。

## 键盘与输入

- 中文经**输入事件**（Unicode 键盘事件）发送到远端；若需要输入法候选窗在
  远端弹出，仍需在远端系统内切换输入法。
- **Alt+Tab、Win 键、Ctrl+Alt+Del** 由本地操作系统/浏览器截获，通常不会送到
  远端（这是 Web 宿主的固有限制，非本插件遗漏）。插件已为 `MetaLeft`/
  `MetaRight` 准备了扫描码，但 Win 键在本地就被系统吃掉，实际收不到。

## 图形

- 图形管线为未压缩位图 + RDP6.1 块压缩传输；未启用 RemoteFX / GFX /
  ClearCode，低带宽下画面流量偏大。
- 音频、驱动器/端口/SmartCard 重定向、多显示器、RemoteApp 未实现。

## 认证与重连

- Kerberos 显式禁用（NLA 使用 NTLM）：KDC 网络访问被离线替身拒绝，不会
  代表用户向域控发起请求。
- 自动重连采用重新握手（非会话快照恢复）；需要重新输入凭据的场景由
  Secret Store 承担。

## 平台

- 提供 `windows-x64`、`linux-x64`、`darwin-x64`、`darwin-arm64` 四个构建。
- **验证范围**：四个目标都在 CI 的真实运行器上通过编译、单元测试与打包。
  但连接真实 Windows 主机的端到端验证目前只在 Windows 上做过；Linux/macOS
  上的实际会话、剪贴板与输入行为尚未在真机复测，属于「能构建、未实跑」。
- Linux 剪贴板走 X11（`x11rb`）；纯 Wayland 会话需要 XWayland 才能同步，
  否则剪贴板功能会静默不可用（连接与画面不受影响）。
- macOS 未做代码签名/公证，首次运行可能被 Gatekeeper 拦截——Sidecar 由 DBX
  作为子进程启动，通常不受影响，但未实测。

## 开发环境差异

- 开发宿主不模拟 `host/requestUserInput` 与真实 Secret Store；证书指纹弹窗、
  密码持久化与权限行为需在真实 DBX 内复测（未签名包 +「允许安装未签名开发包」
  即可复现）。
- Sidecar 以当前用户权限运行（非 OS 沙箱）；`DBX_PLUGIN_DATA_DIR` 下仅存放
  证书指纹白名单。
