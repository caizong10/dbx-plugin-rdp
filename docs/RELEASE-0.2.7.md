# 0.2.7 发布说明

## 平台范围

- Windows x64：远程桌面、键鼠、双向文本及文件/文件夹剪贴板。
- Linux x64、macOS Intel、macOS Apple Silicon：远程桌面、键鼠和双向文本剪贴板；不支持文件/文件夹复制粘贴。

## Windows 剪贴板

- 远端文件夹通过 OLE `IDataObject`/`IStream` 提供虚拟文件，粘贴时分块读取，不再要求预先下载全部文件。
- 支持资源管理器原生复制进度；实际显示方式取决于接收应用。
- 保留临时目录下载与 CF_HDROP 兼容回退、空目录和顶层目录结构。
- 使用代际标识取消旧读取，避免剪贴板更新后混入旧传输数据。
- 诊断日志记录协议元数据，不记录剪贴板正文或文件内容。

## 验证与回退

- 本地 Windows：前端 32 项测试、类型检查、UI 构建；Rust release 69 项测试通过。
- Linux/macOS 的本版本编译、测试和打包由 GitHub Actions 原生运行器验证；尚未进行真实 RDP 会话复测。
- Windows 原有按需粘贴候选已由用户实机测试；本次 0.2.7 版本仍建议安装后检查一次复制与文本切换。
- 0.2.6 旧包与完整备份保留，不随此次提交删除。

发布到个人 GitHub 的安装包为未签名候选包；安装时需在 DBX 插件中心允许未签名开发包。本次不向 DBX 官方插件库提交更新。
